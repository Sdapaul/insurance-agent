🔧 Live / Mock 모드

🔄 모드 전환 방법
우측 상단의 모드 배지를 클릭하면 드롭다운 메뉴가 나타납니다.
모드동작필요 조건
🔄 Auto OpenAI API 크레딧 확인 후 자동 선택 기본값 (권장)
🟢 Live Mode GPT-4o 오케스트레이터 + 모든 도구 사용. 보험다모아 엑셀, 웹 검색, FSS API 모두 활성화 OpenAI API 키 + 크레딧 필요
🔧 Mock Mode 로컬 DB 데이터만 사용. API 없이도 동작하지만 정보가 제한적 API 키 없어도 사용 가능
📌 모드별 답변 차이 예시 — "50대 남성 종신보험 추천"
🟢 Live Mode
보험다모아 엑셀 공시 데이터에서 실시간 조회 → 현재 판매 중인 10개 이상 상품 보험료 비교 → DuckDuckGo로 최신 뉴스 검색 → GPT-4o가 종합 분석 후 추천
🔧 Mock Mode
로컬 정적 DB에서 종신보험 검색 → 사전 저장된 상품 3개 반환. 최신 보험료나 신규 상품은 반영되지 않을 수 있음
🔄 대화 초기화
입력창 왼쪽 🔄 버튼을 클릭하면 대화 내역이 모두 삭제되고 새로운 상담이 시작됩니다.
이전 대화 맥락(나이, 성별 등)도 함께 초기화됩니다.
⚠️ 초기화 후에는 "두 상품 비교해줘"처럼 이전 검색 결과를 참조하는 질문이 작동하지 않습니다. 비교가 필요하면 먼저 상품을 다시 검색하세요.

❓ 자주 묻는 질문 (FAQ)

Q. Mock Mode와 Live Mode 답변이 왜 다른가요?
Mock Mode는 로컬에 저장된 정적 데이터만 사용합니다. Live Mode는 보험다모아 엑셀 공시 데이터, 실시간 웹 검색, FSS API를 모두 활용하므로 훨씬 다양하고 최신 정보를 제공합니다. 가능하면 Live Mode를 사용하세요.
Q. "두 상품 비교해줘"가 작동하지 않아요.
이 기능은 같은 대화 내에서 먼저 상품을 검색한 뒤 사용해야 합니다. 예: "암보험 추천해줘" → (목록 확인) → "앞에 나온 상품 비교해줘". 대화를 초기화했거나 새 세션이면 검색부터 다시 해야 합니다.
Q. 신용점수를 입력했는데 포트폴리오가 안 나와요.
NICE 또는 KCB 점수 중 최소 하나, 그리고 나이와 성별은 반드시 입력해야 합니다. 💳 신용점수 반영 포트폴리오 생성 버튼을 클릭한 후 잠시 기다리면 GPT-4o가 분석을 시작합니다 (약 10~30초 소요).
Q. 치아보험 임플란트 대기기간은 왜 180일인가요?
보험사들은 가입 직후 고비용 치료를 위한 역선택을 방지하기 위해 대기기간(면책기간)을 적용합니다. 임플란트는 통상 180일, 충치 치료는 90일이 업계 표준입니다. 스케일링은 대부분 즉시 보장됩니다. 치아 치료가 임박했다면 치아보험보다 직접 치료비를 지불하는 것이 유리할 수 있습니다.
Q. FSS API 키는 어디서 받나요?
1
회원가입
finlife.fss.or.kr 접속 → 우측 상단 [회원가입]
2
API 활용 신청
[마이페이지] → [API 활용 신청] → 활용 목적 작성 후 제출
3
승인 후 키 발급
심사 당일~익일 승인 → [마이페이지] → [API 키 관리]에서 확인. .env 파일에 FSS_API_KEY=...로 입력
💡 참고: FSS API는 연금저축보험만 지원합니다. 실손·암·치아보험 데이터는 보험다모아 엑셀 또는 스크래핑을 사용하세요.
