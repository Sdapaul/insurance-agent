4. 신용점수 포트폴리오 탭 사용법
신용점수를 반영한 개인 맞춤 보험 포트폴리오 1회 생성

Step 1 — 신용점수 무료 확인

앱·사이트제공 점수확인 방법특징
💚 토스KCB앱 → 신용점수 탭가장 간편, 월 1회 무료
💛 카카오페이NICE앱 → 금융 → 신용점수 조회카카오 계정 연동
🏛️ NICE 지키미NICEcredit.co.kr → 로그인 → 신용점수공식 NICE 조회
📋 올크레딧(KCB)KCBallcredit.co.kr → 신용점수 조회공식 KCB 조회
💡
NICE와 KCB 점수 모두 입력하면 평균값으로 포트폴리오를 구성합니다. 하나만 있어도 괜찮습니다.

Step 2 — 정보 입력

  • 나이: 만 나이 입력 (20~70세)
  • 성별: 남성 / 여성 선택
  • 월 보험료 예산: 만원 단위 (예: 15 → 15만원)
  • NICE / KCB 신용점수: 300~1000점 (하나만 입력해도 됨)
  • 현재 가입 보험: 실손 가입 여부 등 (선택)
  • 건강 특이사항: 고혈압·당뇨 등 (선택)

신용등급별 추천 방향

등급점수 범위특성보험 추천 방향
최우량900~1000금융 우량 고객프리미엄 종신·변액보험, 저축보험 강화
우량750~899일반 직장인모든 보험 표준 추천, 실손+암+종신 기본 구성
보통600~749부채 있는 중간층보장성 보험 집중, 저축 비중 최소화
주의450~599연체 경험무심사·간편심사형 상품 우선 추천
불량300~449신용 위험무심사 상품만 + 신용 관리 병행 권고

5. 장점 vs 단점
AI 보험 상담 어시스턴트의 솔직한 평가

✅ 장점

  • 공식 공시 데이터 기반: 보험다모아(보험협회 공식 운영) 엑셀 공시 데이터를 직접 파싱하여 실제 보험료 제공
  • 실시간 최신 정보: DuckDuckGo 웹 검색으로 최신 뉴스·제도 변경 반영
  • 다양한 보험 종류 통합: 종신·실손·암·치아·간병·연금보험을 한 화면에서 비교
  • 신용점수 맞춤 추천: NICE/KCB 점수를 반영한 5등급별 차별화 포트폴리오
  • 무료 운영 가능: 웹 검색(DuckDuckGo)은 API 키 불필요, Mock 모드로 API 없이도 사용 가능
  • 투명한 근거 제시: 모든 답변에 데이터 출처·신뢰도 표 자동 첨부
  • 연령별 맞춤 포트폴리오: 30/40/50/60대별 특화 보험 구성 가이드 내장
  • 실시간 스트리밍: 긴 답변도 즉시 출력 시작, 기다림 없음

⚠️ 단점 및 한계

  • 보험료는 참고값: 표준 가입 조건 기준. 실제 건강상태·직업·특약에 따라 크게 달라질 수 있음
  • GPT-4o 비용: Live 모드는 OpenAI API 과금 발생 (긴 포트폴리오 질문은 $0.05~$0.15 예상)
  • 보험다모아 봇 차단: 자동 스크래핑 시 mbuster 시스템에 의해 IP 차단 가능 (CDP 모드로 우회 필요)
  • 엑셀 데이터 주기적 갱신 필요: 보험다모아 공시 파일은 수동으로 다운로드하여 교체해야 함
  • 실제 계약 불가: 상담·비교만 가능. 실제 가입은 보험사 다이렉트 또는 설계사 통해야 함
  • 비공시 특약 미반영: 보험사별 특판·특약은 보험다모아에 미표시될 수 있음
  • FSS API 연금보험 한계: 연금저축보험만 지원. 변액연금 등 상세 데이터 없음
  • 신용점수 CDP 조회 조건: Chrome 원격 디버깅 모드 + 해당 사이트 로그인 상태 필요
⚠️
중요 면책 고지: 이 프로그램의 보험 추천은 참고용 정보 제공을 목적으로 합니다. 실제 보험 가입 결정은 반드시 해당 보험사 약관 확인 및 전문 설계사 상담을 통해 진행하시기 바랍니다.

6. 구체적인 보험 상담 팁 15선
AI 어시스턴트를 200% 활용하는 질문 전략

🔹 기본 정보 제공 팁

Tip 01
나이·성별·예산을 함께 명시하세요
보험료는 나이·성별에 따라 2~5배 차이가 납니다. 나이와 성별을 입력하면 실제 공시 보험료 데이터를 조회합니다.
"40세 여성, 월 10만원 예산으로 암보험 추천해줘"
Tip 02
현재 가입 보험을 알려주면 중복 방지
이미 실손보험이 있다면 실손보험 재추천을 건너뜁니다. 불필요한 중복 가입을 방지할 수 있습니다.
"실손보험은 이미 있고, 암보험이랑 치아보험 추가로 뭐가 좋아?"
Tip 03
가족 상황을 포함하면 더 정확한 포트폴리오
기혼·자녀 유무에 따라 종신보험 비중과 교육비 준비 전략이 달라집니다.
"38세 기혼 남성, 자녀 2명, 월 20만원 보험 포트폴리오 짜줘"
Tip 04
건강 상태를 언급하면 맞춤 추천
고혈압·당뇨 등 기저질환이 있으면 일반심사 상품 대신 무심사·간편심사 상품을 우선 추천합니다.
"고혈압 약 먹고 있는데 가입 가능한 암보험 있어?"

🔹 상품 비교 팁

Tip 05
갱신형 vs 비갱신형을 명확히 물어보세요
갱신형은 초기 보험료가 낮지만 5년·10년마다 인상됩니다. 비갱신형은 높지만 고정. 보험 유형별로 어느 쪽이 유리한지 물어보세요.
"50세 남성 실손보험, 갱신형이랑 비갱신형 중 뭐가 유리해?"
Tip 06
보험사 3~5개를 직접 지정해서 비교
전체 시장 조회보다 관심 있는 보험사를 지정하면 더 정확한 비교가 가능합니다.
"삼성화재, 현대해상, DB손해보험 치아보험 비교해줘"
Tip 07
특정 보장 항목을 요구하세요
뇌혈관·심장 담보, 간병인 일당, 임플란트 보장 등 필요한 항목을 명시하면 해당 보장이 포함된 상품을 우선 추천합니다.
"치아보험에서 임플란트 보장 되는 상품만 알려줘"
Tip 08
5세대 실손 전환 전 반드시 확인
기존 1~4세대 실손 보유자는 5세대로 전환 시 보장 범위가 달라집니다. 현재 가입된 세대를 알려주고 전환 득실을 물어보세요.
"3세대 실손 있는데 5세대로 바꾸는 게 이득이야?"

🔹 포트폴리오 구성 팁

Tip 09
연령대별 우선순위를 물어보세요
30대: 종신+실손 기본 / 40대: 암·간병 추가 / 50대: 간병보험 비중 강화 / 60대: 치매보험 + 연금
"50대 진입 전 꼭 가입해야 할 보험이 뭐야?"
Tip 10
신용점수 포트폴리오 탭을 활용하세요
채팅 대신 신용점수 포트폴리오 탭에서 한 번에 개인화 포트폴리오를 생성하면 더 체계적인 결과를 얻을 수 있습니다.
탭 클릭 → 나이·예산·점수 입력 → 버튼 클릭
Tip 11
예산 초과 시 우선순위를 물어보세요
원하는 보험이 예산을 초과하면 "예산 내에서 우선순위를 정해줘"라고 추가 질문하세요.
"예산이 15만원인데 지금 추천 중에서 우선순위 3개만 뽑아줘"
Tip 12
직업을 알려주면 산업재해 대비 특약 추천
현장직·운전직 등은 재해사망·후유장해 특약이 중요합니다. 직업을 언급하면 직업 위험 등급에 맞는 상품을 추천합니다.
"건설업 종사자인데 산재 외에 개인 보험으로 뭐가 좋아?"

🔹 고급 활용 팁

Tip 13
뉴스 기반 최신 이슈를 물어보세요
답변 끝에 자동으로 최신 뉴스가 첨부됩니다. 보험료 인상 예고, 제도 변경 등을 직접 물어볼 수도 있습니다.
"2026년 실손보험 보험료 인상 소식 있어?"
Tip 14
보험료 근거 데이터 출처를 확인하세요
모든 답변 끝의 📋 이 답변의 근거 표에서 보험료가 엑셀 공시 데이터 기반인지, AI 추정인지 확인하세요. ★★★★★가 가장 신뢰도 높음.
근거 표의 신뢰도 ★★★★★ = 보험다모아 공시 데이터

8. 자주 묻는 질문 (FAQ)
API 키 없이도 사용할 수 있나요?
네. Mock 모드로 자동 전환됩니다. 로컬 정적 데이터를 이용한 샘플 응답을 생성하므로 보험 구조 파악·테스트 용도로는 충분합니다. 실제 맞춤형 상담은 Live 모드(API 키 필요)를 권장합니다.
보험료 데이터는 얼마나 최신인가요?
프로젝트 루트에 넣어둔 XLS 파일 기준입니다. 파일명에 날짜가 표시됩니다. 최신 데이터는 보험다모아(e-insmarket.or.kr)에서 직접 다운로드 후 교체하면 됩니다. 보험료는 통상 분기별로 변경됩니다.
신용점수 CDP 조회가 안 됩니다.
Chrome을 --remote-debugging-port=9222 옵션으로 실행하고, NICE 지키미 또는 올크레딧에 먼저 로그인한 상태에서 챗봇에서 "신용점수 조회해줘"라고 입력하세요. CDP 조회가 안 될 때는 신용점수 포트폴리오 탭에서 점수를 직접 입력하는 방식도 가능합니다.
GPT-4o 비용이 얼마나 드나요?
일반 보험 상품 질문 1회에 약 $0.02~0.05 수준입니다. 포트폴리오 추천처럼 긴 응답은 $0.05~0.15 정도 소요됩니다. 비용이 부담스러우면 Mock 모드를 활용하거나, 쿼리를 간결하게 작성하세요.
보험다모아 스크래핑 중 차단됐습니다.
mbuster 봇 차단 시스템으로 IP가 차단된 상태입니다. 수 시간~수일 후 자동 해제됩니다. 차단 중에도 로컬 엑셀 데이터로 챗봇은 정상 동작합니다. VPN 전환 또는 다른 PC에서 CDP 모드로 수집하는 방법을 사용하세요.
치아보험 검색이 안 됩니다.
data/dental_products.py에는 DENTAL_INSURANCE_PRODUCTS 리스트만 있고 함수가 없습니다. 이미 정상 처리되도록 수정되어 있습니다. 만약 치아보험 엑셀 파일이 있다면 루트에 넣어두면 자동으로 인식됩니다.
